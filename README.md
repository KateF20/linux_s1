# Среда для тестирования поведения ОС при нехватке памяти

Итоговое задание по дисциплине «Операционная система Linux» (магистратура «Инженерия машинного обучения», УрФУ).

📄 **Полное описание решения со скриптами и скриншотами — в файле [`Федосеева_Екатерина_Михайловна.md`](Федосеева_Екатерина_Михайловна.md).**

## Что сделано

| Задача | Модуль с решением |
|---|---|
| Процесс с утечкой памяти | `scripts/leak.py`: каждые N секунд выделяет кусок памяти и не освобождает его |
| Автоматическое отслеживание раз в 5 минут | `cron`: `*/5 * * * *` запускает `scripts/monitor.sh` (расписание лежит в `cron.txt`) |
| Мониторинг памяти, CPU, swap, критических событий | `scripts/monitor.sh` дописывает в `logs/monitor.log` вывод `free`, `top`, `ps`, `journalctl -p err` |
| Анализ событий ядра (OOM-killer) | `journalctl -k`: строки `invoked oom-killer` и `Killed process` |
| Диагностический отчёт | `scripts/report.sh` собирает `logs/report.txt`: память, CPU, swap, критические события, OOM |

## Среда

- **Гипервизор:** UTM (QEMU) на macOS — вся работа с утечкой памяти ведётся только внутри виртуальной машины.
- **Гостевая ОС:** Ubuntu Server 26.04 LTS (aarch64), 3.3 GiB RAM.
- **Swap:** файл подкачки `/swapfile` 1.9 GiB, подключён через `/etc/fstab`.
- Мониторинг работает от обычного пользователя (без root): пользователь состоит в группе `adm`, поэтому может читать системный журнал.

## Как я работала

С ВМ я работала с макбука двумя способами:

- **Код — через этот репозиторий.** Скрипты писала в **PyCharm на macOS** (так мне привычнее, чем в редакторе внутри консоли сервера): правлю в PyCharm, затем пушу в гит, затем в ВМ подтягиваю изменения с гита, потом `chmod +x` → запуск.
- **Команды — по `ssh` из терминала мака** (`ssh katef20@192.168.64.2`). В UTM сеть в режиме Shared Network, поэтому ВМ доступна с мака напрямую по IP. Так удобнее, чем в окне консоли UTM: работает копирование и вставка, можно держать несколько терминалов одновременно (например, в одном идёт утечка, в другом смотрю `ps` и `free -h`). Часть команд выполняла и прямо в консоли ВМ в окне UTM.

Запускаются скрипты **только в ВМ**; на маке — редактирование кода, скриншоты и описание.

## Как воспроизвести (в ВМ)

```bash
git clone git@github.com:KateF20/linux_s1.git && cd linux_s1
chmod +x scripts/*.sh scripts/leak.py

crontab -e

# утечка +20 МБ каждые 10 секунд, в фоне и без привязки к терминалу
nohup python3 scripts/leak.py 20 10 > logs/leak.out 2>&1 &

# после срабатывания OOM-killer
./scripts/report.sh
```
